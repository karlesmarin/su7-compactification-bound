  grows x depends on r ALONE.  The vertex condition lam(t - A0) + nu(k - K0) + G0 <= G*(t,k),

3 -- AND THE MONOTONICITY IS A SIGN, NOT A SCAN
====================================================================================================
  At finite k the condition for the active vertex is

     Phi(r,k) = r ( A - (1/2) ln(r + 6 mu/k) ) - nu - C/k >= 0 ,
     C = G_gauge - lam A_gauge - nu (8D)_gauge - 3 mu ,

  and differentiating in k at fixed r,

     k^2 dPhi/dk = 3 mu r / (r + 6 mu/k)  +  C .

  The first term is positive and STRICTLY BELOW 3 mu, so dPhi/dk < 0 whenever C <= -3 mu --
  that is, whenever the gauge sector alone satisfies

     G_gauge - lam A_gauge - nu (8D)_gauge <= 0 .
