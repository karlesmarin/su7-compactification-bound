  Esta objecion es la buena, y por poco se me escapa.  El termino es
     -(1/2) ln xi  x  (numero de modos)
  y en regularizacion zeta el 'numero de modos' de una torre DESPLAZADA es
     sum_{n in Z} 1  =  zeta_H(0, a) + zeta_H(0, 1-a)
  con a el desplazamiento que mete la linea de Wilson.  Y zeta_H(0,a) = 1/2 - a
  DEPENDE de a.  Asi que hay que hacer la cuenta, no suponerla:
     a = 0     :  zeta_H(0,a) + zeta_H(0,1-a) = (1/2) + (-1/2) = 0
     a = 1/4   :  zeta_H(0,a) + zeta_H(0,1-a) = (1/4) + (-1/4) = 0
     a = 1/3   :  zeta_H(0,a) + zeta_H(0,1-a) = (1/6) + (-1/6) = 0
     a = 1/2   :  zeta_H(0,a) + zeta_H(0,1-a) = (0) + (0) = 0
