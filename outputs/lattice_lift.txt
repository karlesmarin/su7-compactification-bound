2 -- AND THE PARITY IS ONE CHARACTER ON THREE COORDINATES, NOT TWO THEOREMS
====================================================================================================
  Carles asked whether the -7/2 driving Theorem 1 and the 2W theorem is one character of the
  lifted lattice.  It is -- and the lift shows it runs on THREE of the five coordinates, not
  the two the paper knew about.  Look at the parity columns:

  multiplet        8D       2U       2W   mod 2
  7(+,+)           -6        2        2   0 0 0
  7(+,-)            8        0       -2   0 0 0
  28(+,+)          16       40        6   0 0 0
  28(+,-)           2       34       -6   0 0 0
  48(+,+)           0       48       12   0 0 0
  48(+,-)          28       36      -12   0 0 0
  84(+,+)          10      346       18   0 0 0
  84(+,-)          80      168      -18   0 0 0
  gauge           -27      -39       -3   1 1 1

  every MATTER multiplet is even in all three : True
  the GAUGE sector is odd in all three        : True

  Therefore, for EVERY bulk content,   8D  ==  2U  ==  2W  ==  1   (mod 2).

  AND THE THREE ARE THE SAME -7/2, not three coincidences.  The gauge sector's only
  half-integer coefficient is the antiperiodic charge-one term, u_(-,1) = -7/2, and each of
  the three coordinates picks it up once:

     8D = 8A_2 - 6B_2 :  B_2 gets u_(-,1) = -7/2,  so -6 B_2 contributes  +21   odd
     2U = 2(16u_(+,2) + B_4) :  B_4 gets the same -7/2,  contributing      -7   odd
     2W = 2( -(u_(+,1)+u_(+,3)) + (u_(-,1)+u_(-,3)) ) : directly            -7   odd

  and the matter multiplets have integer coefficients throughout, so they can only ever
  contribute even amounts to all three.  One half-integer in one gauge coefficient makes all
  three coordinates odd, permanently.

  What that buys, stated once instead of twice:  Theorem 1 (8D odd, so D never vanishes and
  electroweak breaking is never marginal) and the 2W theorem (2W odd, so
  |F(1)-F(0)| >= (31/32) zeta(5) and the two symmetric points are never degenerate) are the
  SAME congruence read on two coordinates.  The third, 2U odd, is new here and has no
  physical reading yet -- U is the coefficient of -ln2 in G, and what an odd 2U forbids a
  content from doing is not known.  It is written down because the character says it, not
  because we have a use for it.

  Verified on random contents:
     20000 random contents, multiplicities to nine, violations : 0   <-- must be 0

  CONTROL -- and it must be able to fail.  The other two coordinates, A_4 and V, are NOT
  forced odd, so the character is a statement about which three and not about all five:
     A_4  takes parities [0, 1] over a handful of contents -- not fixed
     V    takes parities [0, 1] over a handful of contents -- not fixed
